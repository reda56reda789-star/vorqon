# كتالوج VORQON — 10000 منتج

بيانات **تجريبية مولّدة** بسكربت `generate_catalog.py` (بذرة عشوائية ثابتة 42 لإعادة الإنتاج).
ليست منتجات حقيقية من مورد، وليست نسخة من كتالوج أمازون: الأسماء عربية/إنجليزية أصلية، والعلامات عامة/مصرية/عربية، ولا توجد صور أو روابط أمازون.

## التركيز

الأكثر استهلاكاً في مصر والدول العربية أولاً: الغذاء والبقالة والتنظيف والعناية الشخصية والمنزل والمطبخ لها أكبر حصة، ثم الإلكترونيات والملابس والأجهزة.

## الملفات

- `generate_catalog.py` — المولّد (شغّله بـ `python3 generate_catalog.py` لإعادة التوليد)
- `products-10000.csv` — الأعمدة: sku,name_ar,name_en,brand,category_slug,price_egp,compare_at_egp,stock,store_id,origin
- `products-10000.sql` — INSERTs مجمعة (500 في كل دفعة)

## كيفية الاستيراد

1. **عبر مركز البائعين (CSV):** استخدم إجراء `sellerimportcsv` في التطبيق، بصيغة `name_en,name_ar,brand,price,stock,sku` لكل سطر — ملاحظة: هذا الإجراء يتوقع تلك الأعمدة الستة فقط، لذلك للاستيراد الكامل استخدم SQL أو حوّل الملف لتلك الأعمدة.
2. **عبر SQL مباشرة:** `psql -d vorqon -f products-10000.sql` بعد التأكد من وجود جدول `products` بالأعمدة المطابقة وجداول الأقسام والمتاجر.
3. **عبر الـ seed:** يمكن تحويل دفعات من CSV إلى `seed` إضافي بنفس أسلوب `seed/seed-demo.sql`.
