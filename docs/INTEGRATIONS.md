# VORQON — Integrations | التكاملات الخارجية

> **القاعدة: لا ندّعي أن أي تكامل يعمل قبل ربطه فعلياً واختباره.**
> **Rule: no integration is claimed to work until it is actually connected and tested.**
>
> الحالة العامة لكل ما يلي: **غير مفعّلة — جاهزة للربط فقط (NOT ACTIVATED — integration-ready only).**
> الكود في `backend/src/services/payments.js` و `backend/src/services/shipping.js`
> يرفض العمل (503) ما دام `PAYMENT_PROVIDER=none` / `SHIPPING_PROVIDER=none`.

## 1. المدفوعات | Payments

| التكامل | المزود المقترح | ما المطلوب من المالك | الحالة |
|---|---|---|---|
| Visa / Mastercard | Paymob (مصر) أو Stripe (دولي) | حساب تاجر + API Key + Secret + Webhook Secret | غير مفعّلة — جاهزة للربط فقط |
| Meeza | Paymob | حساب تاجر Paymob مفعّل لميزة | غير مفعّلة — جاهزة للربط فقط |
| Vodafone Cash | مزود محفظة معتمد (عبر Paymob أو مباشرة) | حساب تاجر + مفاتيح API | غير مفعّلة — جاهزة للربط فقط |
| Orange Cash | مزود محفظة معتمد | حساب تاجر + مفاتيح API | غير مفعّلة — جاهزة للربط فقط |
| Etisalat Cash | مزود محفظة معتمد | حساب تاجر + مفاتيح API | غير مفعّلة — جاهزة للربط فقط |
| WE Pay | مزود محفظة معتمد | حساب تاجر + مفاتيح API | غير مفعّلة — جاهزة للربط فقط |
| Fawry | Fawry Pay | Merchant Code + Security Key | غير مفعّلة — جاهزة للربط فقط |
| InstaPay / تحويل بنكي | بنك العميل + آلية تحقق ومطابقة يدوية | حساب بنكي للمنصة + نموذج إثبات تحويل | غير مفعّلة — جاهزة للربط فقط |
| الدفع عند الاستلام (COD) | — (داخلي) | لا مفاتيح مطلوبة؛ يُفعَّل من جدول `payment_methods` | **مفعّل في بيانات DEMO فقط** |

**أمان الدفع (ملزم):**
- لا تُخزَّن بيانات البطاقات (رقم البطاقة، CVV، تاريخ الانتهاء) في قاعدة البيانات إطلاقاً — لا يوجد عمود لها في المخطط.
- الدفع يتم عبر صفحة المزود المستضافة فقط، ويُتحقق من Webhook بتوقيعه.
- متغيرات البيئة المطلوبة عند التفعيل: `PAYMENT_PROVIDER` ، `PAYMENT_PROVIDER_API_KEY` ، `PAYMENT_PROVIDER_SECRET` ، `PAYMENT_WEBHOOK_SECRET` (انظر `.env.example`).

## 2. الشحن | Shipping

| التكامل | المزود المقترح | ما المطلوب | الحالة |
|---|---|---|---|
| شحن محلي (مصر) | Aramex / Bosta / شركة محلية | حساب + API Key + Webhook للتتبع | غير مفعّلة — جاهزة للربط فقط |
| شحن عربي / دولي | DHL / Aramex | حساب + API Key | غير مفعّلة — جاهزة للربط فقط |
| تقدير الشحن | مناطق `shipping_zones` في قاعدة البيانات | لا مفاتيح مطلوبة | **يعمل محلياً** (تقدير فقط، بلا تتبع حي) |

- أرقام التتبع الحية لا تُعرض قبل تفعيل الربط الفعلي.
- متغيرات البيئة: `SHIPPING_PROVIDER` ، `SHIPPING_PROVIDER_API_KEY` ، `SHIPPING_PROVIDER_SECRET`.

## 3. العملات وأسعار الصرف | Exchange rates
